# Elite Nexus AgroLink — Prototype

A mobile-friendly static prototype for a Nigerian multi-crop agricultural supply and demand marketplace.

## Features
- Responsive produce marketplace with crop, state, and text search filters.
- Demo/sample listings and buyer requests.
- Forms to add a produce listing or buyer request.
- Browser-local storage for entries created during a demo.
- No external libraries or API keys required.

## Run locally
Open `index.html` in a modern browser, or serve the folder with any static web server.

## Important limitations
This is a front-end demonstration, not a production marketplace. Sample listings are fictional examples and not verified offers. Entries are saved only in the current browser and are not shared across users. There is no account system, server, database, identity verification, chat, image upload, live market-price feed, order management, delivery tracking, payment processing, or admin dashboard.

## Deployment
This project can be hosted on any static web host. For GitHub Pages, open the repository Settings → Pages, choose “Deploy from a branch”, select the default branch and the root folder, and save. Availability depends on repository settings and account permissions.
